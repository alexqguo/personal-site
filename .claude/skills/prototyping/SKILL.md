# Prototyping Skill

Create single-file HTML prototypes focused on conceptualizing UI components, validating user flows, interaction patterns, and information architecture. Prioritize UX fidelity over visual polish.

## Workflow

1. **Build prototype** - Create single HTML file with all screens and interactions
2. **Output** - Save to `./concepts/session-name-v1.html`

## Iterating
When iterating and performing revisions to a design, increment the version number of the filename to go `-v2.html`, `-v3.html`, etc all while keeping the session name the same, to ensure tidy file system organization.

## Core Principles
- Try to think of multiple takes on the same idea. Like if I ask you to prototype a button component, try a serious version, playful version, glass/frosted version, etc.
  - `concepts/turn-indicator-2.html` is a good example of this
- If applicable, cover all possible UX states
